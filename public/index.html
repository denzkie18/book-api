Host your own
Free to run, no API keys or database needed.

Deploy with Vercel





One click
  1. Click Deploy with Vercel.
  2. Sign in with GitHub, GitLab or Bitbucket.
  3. Keep the defaults and press Deploy.
  4. Open your new URL. The explorer is at /.


From a fork
  1. Fork denzkie18/book-api.
  2. Go to vercel.com/new and import your fork.
  3. Press Deploy. Every push redeploys automatically.


Vercel CLI
npm i -g vercel
vercel --prod


Run locally
git clone https://github.com/denzkie18/book-api.git
cd book-api
npm ci
npm start
Needs Node.js 20+. Opens at http://localhost:3000.




Your API base URL
Once deployed, call the API from anywhere:
curl "https://your-app.vercel.app/api/v0/novel/latest"


Heads up: on Vercel the cache and request pacing live in memory and reset when an instance restarts, so upstream rate limits may be hit sooner under heavy traffic. For high volume, use a long-running host such as Render, Railway or Fly.io.
